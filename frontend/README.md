# Website Archaeologist frontend

React + TypeScript + Vite frontend using TanStack Query and TanStack Router.

## Run

Start the backend on port 8000, then:

```bash
npm install
npm run dev
```

Open `http://localhost:5173`.

Set a deployed API URL when needed:

```bash
VITE_API_BASE_URL=https://your-api.example.com npm run build
```

The production build is written to `dist/` and can be deployed to Vercel or Netlify.
